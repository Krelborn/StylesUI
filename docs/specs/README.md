# Specs

Each file is the spec a StylesUI feature was built from, written with a coding agent through the [agent-skills](https://github.com/addyosmani/agent-skills) `spec-driven-development` workflow and approved before any code. [`AGENTS.md`](../../AGENTS.md) describes where a spec lives while its feature is in progress.

- [Palettes](2026-10-11-palettes.md): split colour from themes and add the Mist, Paper and Dusk palettes. Released in 0.5.0 ([#42](https://github.com/Krelborn/StylesUI/pull/42)).
- [Markdown Review follow-ups](2026-10-12-markdown-review-follow-ups.md): status and per-colour outline Buttons, aligned placements and popover focus, for gaps [Markdown Review](https://github.com/Krelborn/markdown-review) found. Released in 0.7.0 ([#48](https://github.com/Krelborn/StylesUI/pull/48)).
- [Compact checkbox and radio](2026-10-13-compact-checkbox-and-radio.md): shrink the box onto the space scale and add a hover halo. Released in 0.8.0 ([#50](https://github.com/Krelborn/StylesUI/pull/50)).
- [Compact switch](2026-10-13-compact-switch.md): bring the Switch's track, text and halo in line with Checkbox and Radio. Released in 0.8.0 ([#51](https://github.com/Krelborn/StylesUI/pull/51)).
