# StylesUI

A tree-shakable React 19 component library styled with CSS modules and CSS custom properties. Every
component is themeable, supports light and dark modes, and every story runs automated WCAG 2.2 AA
checks.

<Canvas of={ThemeShowcaseStories.AllCombinations} />

## Installation

The package is published to GitHub Packages. Add an `.npmrc` to your project:

```
@krelborn:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

Set `GITHUB_TOKEN` to a classic personal access token with the `read:packages` scope, then install:

```sh
pnpm add @krelborn/stylesui
```

## Setup

Import the global stylesheet once at your app root. It provides the reset, colour palette, design
tokens and themes:

```tsx
import "@krelborn/stylesui/styles.css";
```

Each component imports its own CSS, so only the styles for components you use end up in your bundle.

Themes use CSS `light-dark()`, so set your bundler's CSS target to at least Chrome/Edge 123,
Firefox 120 and Safari 17.5. A lower target rewrites `light-dark()` into fallbacks that stop colour
modes nesting. With Vite:

```ts
export default defineConfig({
  build: { cssTarget: ["chrome123", "edge123", "firefox120", "safari17.5"] },
});
```

## Usage

```tsx
import { Button, Card, Heading, Text } from "@krelborn/stylesui";

export function Welcome() {
  return (
    <Card as="article">
      <Heading level={2}>Welcome</Heading>
      <Text as="p" tone="muted">
        Components render semantic HTML and accept every prop of the element they render.
      </Text>
      <Button onClick={() => console.log("Started")}>Get started</Button>
    </Card>
  );
}
```

## Components

The sidebar groups the components by what they are for:

- **Primitives**: `Box`
- **Layout**: `Card`, `Center`, `Cluster`, `Cover`, `Divider`, `Frame`, `Grid`, `PageLayout`,
  `Row`, `Sidebar`, `Stack` and `Switcher`
- **Typography**: `Code`, `Heading`, `Kbd`, `Prose` and `Text`
- **Actions**: `Button` and `IconButton`
- **Navigation**: `Link`, `NavList` (with `NavListGroup` and `NavListItem`), `SkipLink` and
  `Tabs` (with `TabList`, `Tab` and `TabPanel`)
- **Forms**: `Checkbox`, `Field`, `Fieldset`, `Radio`, `RadioGroup`, `SegmentedControl` (with
  `Segment`), `Select`, `Switch`, `Textarea` and `TextInput`
- **Feedback**: `Alert`, `Badge`, `Counter` and `StatusDot`
- **Overlays**: `Popover` and `Tooltip`
- **Data display**: `Avatar`, `AvatarGroup` and `Listbox` (with `ListboxOption`)
- **Utilities**: `VisuallyHidden`
- **Theming**: `Theme`

Themes give each status (danger, success, warning and info) a fill, a text and a subtle colour, and
give form controls a border that keeps 3:1 against the page. `Alert`, `Badge` and the form
components are built on them.
