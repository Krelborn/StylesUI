# Composition

## Box and the `as` prop

`Box` is the primitive every StylesUI component is built on. It renders the element given in `as`
(`div` by default) and accepts every prop that element supports, including `ref`. The props are
type-checked against the chosen element, so `href` is accepted with `as="a"` and rejected with
`as="span"`.

<Canvas of={BoxStories.AsLink} />

Most components are polymorphic in the same way, so pick the element that fits the content:

<Canvas of={CardStories.WithContent} />

The rest render the element their job needs and accept the props of that element. What each
component renders:

- **Any element, given in `as`**: `Box`, `Card`, `Center`, `Cluster`, `Cover`, `Frame`, `Grid`,
  `PageLayout`, `Prose`, `Row`, `Sidebar`, `Stack`, `Switcher`, `Text`, `Theme` and
  `VisuallyHidden`.
- **A `span`, `a` or `button`, given in `as`**: `Badge`.
- **A `div`, `li` or `section`, given in `as`**: `Field`.
- **One fixed element**: `Alert` (`div`), `Avatar` and `AvatarGroup` (`span`), `Button` (`button`),
  `Code` (`code`), `Counter` (`span`), `Divider` (`hr`), `Fieldset`, `RadioGroup` and
  `SegmentedControl` (`fieldset`), `Heading` (`h1` to `h6`, from `level`), `Kbd` (`kbd`),
  `Select` (`select`), `SkipLink` (`a`), `StatusDot` (`span`), `Tabs`, `TabList` and `TabPanel`
  (`div`), `Tab` (`button`), `Textarea` (`textarea`) and `TextInput` (`input`).
- **An `input` inside the `label` that names it**: `Checkbox`, `Radio`, `Segment` and `Switch`.
- **An `a`, or a component that renders one**: `Link`.

A fixed-element component leaves out the native props it replaces, such as `size` on `TextInput`
and `Select`. On `Checkbox`, `Radio`, `Segment` and `Switch`, `className` and `style` go to the label,
and `ref` and every other prop go to the input.

## Link and router components

`Link` renders an anchor. Its `as` takes no other element, only a component that renders an
anchor, such as your router's link. `Link` then accepts that component's props in place of the
anchor's:

```tsx
<Link as={RouterLink} to="/settings" underline="hover">
  Settings
</Link>
```

<Canvas of={LinkStories.AsComponent} />

`Link` passes the component a `className` and `data-*` attributes, and the component must pass
them on to its anchor or the link is unstyled. Nothing checks that it does.

Two limits come from how the component's props are read:

- A link component whose props depend on a type parameter, such as one that checks `to` against
  your routes, has them read at that parameter's constraint, so checking each link's `to` does not
  work through `as`. Use the router's own way of wrapping an anchor component instead. TanStack
  Router documents `createLink` for this.
- A class component is accepted but cannot be given a `ref`.

If your own `jsx-a11y` lint settings map `Link` to `a`, the `anchor-is-valid` rule reports a `Link`
whose destination is the component's own prop, because it has no `href`, so disable the rule on
that line.

## Raw HTML in Prose

`Prose` styles the raw elements inside it, for content that cannot be written one component per
element, such as rendered markdown. Components and prose mix, with these rules:

- A StylesUI component inside prose keeps every property its own class declares.
- Prose spaces only the raw elements it styles. A component placed directly in prose gets no
  spacing, so give it a margin from `--sui-prose-flow`, as the card below does.
- A component rendered through `as` as an element prose styles, such as `<Text as="code">`, still
  takes the prose properties it does not set itself.
- A raw element inside a component inside prose, such as a bare `p` in a `Card`, is styled as
  prose. There is no opt-out.
- `size` scales the body text only. Headings keep the size of their level.

## Empty states

StylesUI has no empty-state component, because the layout components already make one. When a list or a pane has
nothing to show, say so with a heading and a sentence of muted text. When the user can do something about it, add an
action:

- `Cover` with `minimumHeight="100%"` centres the message vertically in its pane, which needs a set height, such as a
  flex or grid item or a fixed `blockSize`;
- `Center` with `intrinsic={true}` and `width="prose"` centres it horizontally at a readable width, and
  `textAlign: "center"` centres its lines;
- a `Stack` with `align="center"` holds the `Heading`, the muted `Text` and the action.

```tsx
<Cover minimumHeight="100%">
  <Center intrinsic={true} style={{ textAlign: "center" }} width="prose">
    <Stack align="center" gap={2}>
      <Heading level={2} size="lg">
        No pull requests yet
      </Heading>
      <Text as="p" tone="muted">
        Connect a repository to see the pull requests waiting for your review.
      </Text>
      <Button>Connect a repository</Button>
    </Stack>
  </Center>
</Cover>
```

Choose the heading level from where the empty state sits in the page outline, as for any heading. An empty state in
a pane under a level 2 heading takes level 3. `size` keeps it the same size whatever its level.

## Class names and styles

Every component accepts `className` and `style` and merges `className` with its own class. To
restyle a component, prefer overriding the `--sui-*` tokens it reads, as described in
[Theming](?path=/docs/guides-theming--docs).

## Building your own components

Build on `Box` rather than rendering DOM elements directly. `PolymorphicProps` combines your own
props with every prop of the element given in `as`:

```tsx
import type { JSX } from "react";
import type { BoxElement, BoxProps, PolymorphicProps } from "@krelborn/stylesui";
import { Box } from "@krelborn/stylesui";

interface PillOwnProps {
  tone?: "info" | "success";
}

type PillProps<E extends BoxElement = "span"> = PolymorphicProps<E, PillOwnProps>;

export function Pill<E extends BoxElement = "span">({ as, tone = "info", ...rest }: PillProps<E>): JSX.Element {
  // PillProps<E> already guarantees the props match `as`
  const boxProps = rest as BoxProps<"span">;

  return <Box {...boxProps} as={(as ?? "span") as "span"} data-tone={tone} />;
}

<Pill as="a" href="/changelog" tone="success">
  Released
</Pill>;
```
